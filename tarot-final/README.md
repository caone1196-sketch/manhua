- Chỉ giữ **tên lá bài** chữ vàng serif Roman nổi trực tiếp trên tranh ở cạnh dưới
- Cùng mặt mẫu + màu da + chất vẽ với ảnh reference `tarot-prompts/ref/2-mj-clean.png`
