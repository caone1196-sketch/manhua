# manhua

Bộ prompt **Tarot 22 lá Major Arcana** — semi-realistic gothic fantasy, lấy lá THE STAR làm chuẩn style.

📁 Vào thư mục [`tarot-prompts/`](tarot-prompts/) để xem:
- `README.md` — hướng dẫn + danh sách 22 lá
- `_STYLE-LOCK.md` — luật đồng bộ (da/váy/bối cảnh khóa cứng, tóc/mắt đổi theo lá)
- `PART-1..4` — prompt chi tiết từng nhóm lá (tiếng Anh, copy-paste)
- `cards/*.txt` — 22 file prompt thuần, mỗi lá 1 file
- `prompts.json` — toàn bộ prompt dạng JSON để gen batch
